AKADEMIK & PRAKTIK MANDIRI

Sistem Aplikasi Perpustakaan Digital

Role: Fullstack (Backend & Frontend)

📌 Overview

Aplikasi web berbasis Laravel untuk mendigitalisasi pengelolaan katalog buku, keanggotaan, dan transaksi peminjaman perpustakaan secara efisien dan terorganisir.

⚠️ Problem

Proses pencatatan sirkulasi buku, tracking status peminjaman, dan pendataan anggota yang dilakukan secara konvensional rawan redundansi data, kehilangan catatan transaksi, dan menyulitkan rekapitulasi data inventaris.

💡 Solution

Membangun aplikasi web terpusat dengan basis data relasional MySQL untuk mengotomatisasi pencatatan peminjaman, pengelolaan status anggota, dan pengelompokan buku berdasarkan kategori dengan integritas data yang terjamin.

🚀 Fitur Utama

  • Manajemen Katalog Buku: Pendataan judul, pengarang, penerbit, dan pengelompokan kategori.
  • Manajemen Anggota: Pendataan identitas anggota perpustakaan secara terpusat.
  • Sistem Transaksi Peminjaman: Logika pencatatan sirkulasi peminjaman dan pengembalian buku.
  • Kategori & Klasifikasi: Pemisahan entitas buku dengan relasi tabel kategori.

TEKNOLOGI DIGUNAKAN

PHP Laravel MySQL Git

PROSES PENGEMBANGAN

  1. Perancangan ERD relasi buku, kategori, anggota, & peminjaman.
  2. Implementasi Database Migration & Eloquent ORM.
  3. Pembuatan controller & logika validasi request.
  4. Integrasi tampilan antarmuka (blade) dengan data backend.
  5. Version control menggunakan Git.

HASIL & METRIK

Aplikasi berfungsi fungsional untuk mengelola seluruh sirkulasi data buku dan anggota.
